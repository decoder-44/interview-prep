# Interview Prep Application

A comprehensive full-stack application for interview preparation with mock interviews, question bank, performance tracking, and AI-powered feedback.

## Features

- **User Authentication** - Register and login with JWT tokens
- **Question Bank** - Browse questions by category and difficulty
- **Mock Interviews** - Practice interviews with timed sessions
- **Performance Tracking** - Track scores and metrics
- **AI Feedback** - Get intelligent feedback on responses
- **Real-time Features** - WebSocket support for live interactions

## Tech Stack

### Backend
- Spring Boot 3.5.14
- Java 21
- PostgreSQL
- Spring Security & OAuth2
- JWT Authentication
- JPA/Hibernate
